# luit-nov-2025-white-ai

AWS AI Foundational Exam Prep - Study Materials

## Week 1, Call 1: Introduction to AI/ML

This session covered foundational concepts in machine learning:

- **AI/ML/DL/GenAI distinctions** - Understanding the relationship between artificial intelligence, machine learning, deep learning, and generative AI
- **Learning types** - Supervised vs unsupervised learning, classification vs regression
- **Model performance** - Underfitting and overfitting concepts
- **Class imbalance** - Challenges with imbalanced datasets
- **ML lifecycle** - End-to-end workflow: data preparation, model training, prediction, and evaluation
- **Feature importance** - Understanding which features drive model predictions
- **Hands-on practice** - Built and evaluated a Decision Tree classifier on the Iris dataset

See `caip_01_01/caip_week1_call1.ipynb` for detailed notes, definitions, and code examples.

## Week 1, Call 2: Model Evaluation Metrics

This session focused on evaluating classification models:

- **Evaluation metrics** - Accuracy, precision, recall, and F1 score
- **Confusion matrices** - Raw and normalized visualizations to understand prediction errors
- **Limitations of accuracy** - Why accuracy alone can be misleading, especially with imbalanced datasets
- **Real-world context** - How different metrics matter for different business problems (e.g., gun detection on Facebook Marketplace)
- **Model comparison** - Built and compared Decision Tree and Random Forest classifiers on the Titanic dataset

See `caip_01_02/caip_week1_call2.ipynb` for detailed notes, definitions, and code examples.
